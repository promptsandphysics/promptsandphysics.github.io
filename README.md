# Prompts and Physics

Source for the site published with GitHub Pages.

## Files

| File | What it is |
|------|------------|
| `index.html` | The homepage. Served at the site root. |
| `about.html` | A second page, to show how paths map to URLs. |
| `style.css` | Styling shared by both pages. |

## How it publishes

Pages watches the `main` branch. Push a commit, wait a minute, refresh.
There is no build step — these are plain files served as-is.

## Editing locally

Open `index.html` in a browser to preview. Nothing to install, no server needed.
